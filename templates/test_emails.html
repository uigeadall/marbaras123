How to use

Add query parameters to the URL:

  • ?email=you@example.com — recipient for test sends
  • &type=welcome — welcome email only
  • &type=order — order confirmation only
  • &type=simple — simple test email only
  • &type=all — all types (default)

Example: /test-emails/?email=test@example.com&type=all
