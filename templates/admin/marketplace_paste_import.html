📋 Paste orders from Amazon / Etsy

No file needed — copy the rows straight from your order report (or a spreadsheet) and paste them below. We parse them the same way as a CSV upload, de-duplicate against existing orders, and you can print DPI labels right after.

Two ways to paste — both work:
  1. An address block straight from the order page, one line each:
    Name / Street / Postal code City / Country. Paste several at once by leaving a blank line between them. Pick the marketplace on the left first.
  2. A spreadsheet/report with a header row (column names like order-id, buyer-name, ship-address-1…) as the first line. Tabs, commas, semicolons all auto-detected.
