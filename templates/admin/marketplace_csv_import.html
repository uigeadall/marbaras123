📦 Import orders from Amazon / Etsy CSV

Upload the CSV/TSV export from Amazon Seller Central or Etsy Shop Manager. We'll parse it, de-duplicate against previously-imported orders, and you can then print DPI labels individually or in bulk.

🟠 Amazon

  1. Log in to Seller Central
  2. Open Reports → Fulfillment by Merchant → Orders
  3. Request report → Download Unshipped Orders
  4. Upload the .txt / .csv file below ↓

🟡 Etsy

  1. Log in to Etsy Shop Manager
  2. Go to Orders & Shipping
  3. Click Download CSV (top-right)
  4. Upload the .csv file below ↓
